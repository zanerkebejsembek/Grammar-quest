# Grammar Quest — онлайн ойын

Оқушылар QR арқылы кіреді; 5 сөйлем; әр тапсырмаға тек 1 жауап; мұғалім панелінде ұпайлар 3 секунд сайын жаңарады.

## Интернетке жариялау
1. Осы жобаны GitHub репозиторийіне жүктеңіз (server.js, package.json, public қалтасы).
2. Railway.app немесе Node.js қолдайтын хостингке репозиторийді қосыңыз. Start command: `npm start`.
3. Хостингтің Environment Variables бөлімінде `TEACHER_PASSWORD` айнымалысына өз құпиясөзіңізді қойыңыз.
4. Тұрақты нәтижелер үшін серверге persistent volume қосып, `DATA_FILE=/data/results.json` орнатыңыз. Әйтпесе сервер қайта іске қосылғанда ұпайлар жоғалуы мүмкін.
5. Сайттың берілген HTTPS сілтемесін ашыңыз. Мұғалім панелі: `https://СІЗДІҢ-САЙТ/teacher`.
6. Мұғалім панеліне кіріп, QR-кодты тақтадан көрсетіңіз. Оқушылар телефонмен сканерлейді.

## Жергілікті тексеру
Node.js орнатылған компьютерде `npm install`, содан кейін `TEACHER_PASSWORD=yourpassword npm start` (Windows PowerShell: `$env:TEACHER_PASSWORD='yourpassword'; npm start`). `http://localhost:3000/teacher` мұғалімге арналған.

## Маңызды
- Бұл файлдар өздігінен жарияланған сайт емес. QR тек жоба интернетке орналастырылған соң сыртқы телефондарда жұмыс істейді.
- Оқушы сессиясы браузерде сақталады, сол браузерден қайта кірсе тапсырмаларды қайта бастай алмайды. Бірақ басқа браузер/құрылғы арқылы жаңа атпен қайта тіркелуді толық болдырмау үшін мектептік аккаунт арқылы кіру жүйесі қажет.
- Мұғалім құпиясөзін оқушыларға бермеңіз. Оқушылардың аты-жөні мен нәтижелері серверде сақталады; мектептің деректерді қорғау ережелерін сақтаңыз.
